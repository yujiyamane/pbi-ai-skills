Power BI × AI agent skills for Claude Code and GitHub Copilot. Automate the full PBI development lifecycle.

Skills

pbi-drafter ✅ Stable

Generate a full Power BI Project (PBIP) from a /*FACTORY*/ config block. Produces M Query, TMDL semantic model, PBIR report layout, and DAX measures in one command.

PBIP TMDL Python
350 TDD tests passing
pbi-drafter-configurator ✅ Stable

Analyse a CSV or Excel file and auto-classify columns into SUM/CNT/AVG/KEY/OTHER/DATE slots. Outputs a ready-to-use /*FACTORY*/ config block for pbi-drafter.

CSV Excel Config
pbi-user-guide-drafter ✅ Stable

Parse a PBIP folder and generate a professional DOCX user guide with page-by-page descriptions, KPI definitions, boilerplate sections, and optional live Playwright screenshots.

DOCX PBIR Playwright
pbi-tester ✅ Stable

Static quality analysis — 50+ checks across 10 categories: layout, text quality, format strings, accessibility, design consistency, TMDL model, relationships, security, performance, and cross-layer consistency.

Static Analysis Quality 50+ checks
pbi-deployer ✅ Stable

One-command deploy to Power BI Service or Microsoft Fabric via fabric-cicd. Includes pre-deployment validation and post-deployment status check.

fabric-cicd Deployment CI/CD
pbi-rls-auditor 🚧 Coming Soon

RLS role testing with DAX evaluation and audit trail generation. Verify row-level security rules without deploying to Power BI Service.

RLS Security Audit
pbi-optimiser 🚧 Coming Soon

Performance profiling and optimisation recommendations. VertiPaq Analyser integration, measure DAX profiling, and aggregation suggestions.

Performance VertiPaq DAX

Installation

# Install all skills
claude skills install https://github.com/yujiyamane/pbi-ai-skills

# Or install a single skill
claude skills install https://github.com/yujiyamane/pbi-ai-skills/pbi-drafter

# Use in chat
"Use pbi-drafter-configurator to analyse my CSV at C:\data\sales.csv"

# Skills are in .github/skills/ — Copilot workspace detects them automatically.

# Reference in Copilot Chat:
#skills/pbi-drafter-configurator Analyse this CSV for a dashboard config

# Copy SKILL.md from the relevant skill folder into your project context,
# or add it as a .cursorrules / Codex system file.

# pbi-drafter SKILL.md:
pbi-ai-skills/pbi-drafter/SKILL.md

# pbi-tester SKILL.md:
pbi-ai-skills/pbi-tester/SKILL.md
